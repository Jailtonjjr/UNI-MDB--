# UniMDB-Backend   

Olá! Me chamo Jailton, sou desenvolvedor focado em backend e atualmente estudo frontend e desenvolvo aplicações utilizando C# e .NET. Tenho experiência na construção de APIs REST, organização de arquitetura em camadas e integração com banco de dados.

A ideia deste projeto é desenvolver um site de avaliação de filmes dos quais os usuarios possam salvar seus filmes favortiso fazer e reviews e procurar avaliações de filmes, neste projeto atuei no desenvolvimento da camada de infraestrutura da aplicação, sendo responsável pela implementação dos Repositories e pela estruturação dos componentes necessários para integração da API.

Desenvolvi a API de favoritos, incluindo toda a lógica de criação, listagem e gerenciamento, além de implementar os serviços na camada de application, garantindo a separação de responsabilidades e organização da arquitetura, também participei da construção dos services, contribuindo para a lógica de negócio da aplicação.
neste projeto tambem participei do frontend desenvolvendo o sistema de sessões, e fazendo a pagina de reviews e favoritos.
